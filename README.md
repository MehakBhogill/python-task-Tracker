# python-task-Tracker
Task Tracker is a simple CLI-based project used to manage and track tasks such as pending, completed, and ongoing work. It helps improve programming skills by practicing file handling, user input processing, and command-line application development in Python.
A simple Command Line Interface (CLI) based Task Tracker application built using Python. This project helps users manage daily tasks directly from the terminal.

**Features**
Add new tasks
Update existing tasks
Delete tasks
Mark tasks as:
Todo
In Progress
Done
List all tasks
Filter tasks by status
Store tasks permanently using JSON file
**Technologies Used**
Python 3
JSON
File Handling
argparse
Object-Oriented Programming (OOP)
**Project Structure**
python-task-Tracker/
│
├── task.py

**Installation**
Clone Repository
git clone https://github.com/MehakBhogill/python-task-Tracker.git
cd python-task-Tracker
**Usage**
Add Task
python task.py add "Learn Python"
Update Task
python task.py update 1 "Learn Spring Boot"
Delete Task
python task.py delete 1
Mark Task as In Progress
python task.py mark-in-progress 1
Mark Task as Done
python task.py mark-done 1
List All Tasks
python task.py list
List Tasks by Status
python task.py list done
